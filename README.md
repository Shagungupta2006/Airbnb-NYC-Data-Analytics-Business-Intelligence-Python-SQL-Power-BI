# 🏠 Airbnb NYC Data Analytics & Business Intelligence

## 📌 Project Overview

The **Airbnb NYC Data Analytics & Business Intelligence Project** is an end-to-end data analytics project focused on analyzing Airbnb listings across New York City.

This project uses **Python, MySQL, and Power BI** to clean, analyze, visualize, and extract meaningful insights from Airbnb listing data.

The analysis focuses on **pricing, room types, neighborhoods, hosts, availability, ratings, and estimated revenue**.

---

## 🎯 Project Objectives

- Analyze Airbnb listings across NYC boroughs and neighborhoods
- Understand pricing patterns
- Analyze room type and property type distribution
- Identify top neighborhoods and hosts
- Analyze listing ratings and reviews
- Explore availability patterns
- Analyze estimated annual revenue
- Perform exploratory data analysis using Python
- Perform SQL-based business analysis using MySQL
- Build an interactive Power BI dashboard
